## Summary

**入门坡道，不是答案本** —— 给零化学基础的玩家**一条能跑通的线**，
但**不给最优解、不给豁免、不给完整路线图**。

## Overview

### 它的角色已经"被定死了"（概念文档有一整节）

> **用户原话**：「我们并不拒绝一点化学知识都不懂的玩家，我们会提供**百科**，
> 告诉小白可以怎么提炼、转化、合成产物；但是我们依旧支持玩家自己去创造不同的流程去优化原有流程 ——
> **我们只是提供一个解，但鼓励玩家去自己创造更多**。」
>
> **概念文档的结论**：**「这条把百科的角色定死了：它是入门坡道，不是答案本。」**

### 拿什么 / 不拿什么（**这张表是概念文档原文**）

| 百科**给**什么 | 百科**不给**什么 |
|---|---|
| 一条**可行解**（某产物的**一种**提炼 / 转化 / 合成路径） | 该产物的**最优解** |
| 每一步的条件（温度 / 压强 / 催化剂 / 停留时间） | **任何豁免** —— **条件不对，百科上那条路照样出意外产物、照样炸** |
| 让零化学基础的玩家**把第一条线跑起来** | 后续产物的**完整路线图**（仍靠参数漂移、异常点探测、玩家自带知识去发现） |

### 设计测试（概念文档原文，已成为本系统的硬规则）

> 争「百科直接给这个产物的**最优参数**」 vs 「百科给**一条可行解**，
> 并让玩家**看见它的代价**（能耗 / 纯度 / 耗时）」 → **选后者**。

### 为什么必须这样（**概念文档给了三条理由**）

1. **它是 P3 的前提，不是 P3 的反例** —— P3 说"工艺属于玩家"，
   那玩家得**先有一条能跑通的线**才谈得上优化。**百科负责把人送到起跑线上。**
2. **它把"卡住"变成"想优化"** —— 百科没有消灭挑战，
   只是把挑战从「我完全不知道怎么办」移到「**这条解不够好，我要找更好的**」。
   **这正是「表达与创造」的入口。**
3. **它与 P2 不冲突** —— **百科给的是路线，不是豁免。**

### 它与另外两条约束的关系

**① L4 的分工**（概念文档 line 205）：
> **「8 元素、原子量、阳极的析氯/析氧依据、规格阈值、灾难边界 —— 这些【事实】全部收进百科；
> 界面只显示【当前状态 + 后果】。降认知负荷靠"把事实放对位置"，不靠删严谨性。」**
> → **B7 是"事实"的家**；界面（B11）只承担**决策**。

**② 它是三条发现途径之一**（概念文档 line 49）：
> 「教程只教 **6 个操作**，其余靠 **参数漂移、百科残页、异常点探测** 三种游戏内途径发现。」
> → **"百科残页"** 这个词说明：**百科本身也是【部分可发现】的。**

**残页的获取机制**：✅ 已定 —— **来自探索**（⑦）。

**初始百科的边界**：✅ 已定 —— **刚好够跑通第一条线**（水电解 → H₂ + O₂，⑥）。

**与 B9 的分工**：✅ 已定 —— **事实进百科、工艺进 B9**（⑧）。

**与 B8 的分工**：✅ 已定 —— **知识解锁（B7）≠ 机制解锁（B8）**，见澄清 3。

## Player Fantasy
**方向：**「**有人告诉了我第一步。**」

B7 给的不是答案，而是【**起跑线**】—— 它的情绪价值在于
**把"我不知道从哪开始"这一种绝望去掉**，而**不碰"我可以做得更好"这一种野心**。

**反例**：百科给了最优参数。**那它就从坡道变成了天花板** —— 玩家会照着抄，然后不再想。

**而它与"发现"的关系是互补的**：
- **百科**给你**第一条线**（别人走过的路）；
- **残页**在你**自己走到那里**之后才出现（澄清 1）；
- **你发明的工艺**进 B9（澄清 2）。
→ **三者合起来，才是"发现"的完整循环。**

| ③ | **给"看见代价"**（能耗 / 纯度 / 耗时）—— 用 A6 的表达（**单旋钮切片**）。 | ✅ 已定 | 设计测试 |
| ④ | **不给后续产物的【完整路线图】** —— 那些靠发现。 | ✅ 已定 | 概念文档的"不给"表 |
| ⑤ | **它是"事实"的家**（L4 的分工）—— 8 元素 / 原子量 / 阳极依据 / 规格阈值 / 灾难边界都在这里；**界面只显示当前状态与后果**。 | ✅ 已定 | L4 |
| ⑥ | **百科是【部分可发现】的**：**初始条目 = 刚好够跑通第一条线**（水电解 → H₂ + O₂）；**其余靠【残页】获得**。 | ✅ 已定 | 概念文档的"给"表 + line 49 的"百科残页" |
| ⑦ | **残页来自【探索】**：下潜 / 到达新深度 / 找到新矿脉 / 发现异常点 —— **不是靠做实验**。 | ✅ 已定 | 用户拍板（见澄清 1） |
| ⑧ | **事实进百科，工艺进 B9**：玩家实验发现的【化学规律】会记进百科；玩家连出来的【工艺方案】进 B9。 | ✅ 已定 | 用户拍板（见澄清 2） |
| ⑨ | **百科不得自己计算** —— 所有数值必须能追溯到上游（A3 的求值 / A6 的代价 / B3 的档位）。 | ✅ 已定 | 三条上游契约（都是同一句话的三种形式） |

### 澄清 1：**三条发现途径通向的是【三批不同的知识】**（不是同一批的三把钥匙）

概念文档把这三条**并列**：**参数漂移 · 百科残页 · 异常点探测**。既然并列，它们就不该是"同一批知识的三条获取路"：

| 途径 | 动作 | 它给的知识 |
|------|------|------------|
| **参数漂移** | **实验** | **通用规律**（"温度偏高会出副产物"） |
| **百科残页** | **探索**（下潜 / 新深度 / 新矿脉） | **具体路线**（"某条路可以做出 X"） |
| **异常点探测** | **观察** | **线索**（"这里不对劲"） |

> **所以 ⑦ 的推论是：残页不是"靠实验获得的条目"，而是"你走到那里才知道的知识"。**
> **若把残页做成实验奖励，那它就与"参数漂移"重合了 —— 三条途径会塌成一条。**

### 澄清 2：**"事实进百科、工艺进 B9"让"发现"这个循环闭合**

| 玩家做了什么 | 它是什么 | 归属 |
|--------------|----------|------|
| 实验后发现"**原来氯会氧化**" | **事实**（客观的化学规律） | **进百科（B7）** |
| 据此连了一条工艺 | **工艺**（玩家的连接方案） | **进 B9（工艺卡）** |

> **两者都"属于玩家"，但归属不同：一个进【知识库】，一个进【作品集】。**
>
> 而这个划分的价值在于：**"发现"这个循环终于闭合了** ——
> 玩家自己搞明白的事实**会被记下来**（他下次不用靠记忆），
> 而**他发明的东西仍然是他的作品**（P3 完整）。

### 澄清 3（F-B7-1）：**"知识解锁"与"机制解锁"不是同一件事**

B7 的"残页"与 B8 的"渐进解锁"听起来很像（都是"一点点给你东西"），**但它们给的东西不同类**：

| | **B7（本系统）** | **B8 渐进解锁** |
|---|---|---|
| 管什么 | **你知道吗** —— 这条路线存在 | **你能用吗** —— 机制 / 参数 / 决策复杂度是否可用 |
| 状态 | 哪些条目已获得、哪些还是残页 | 哪些机制/参数已开放 |
| 来源 | **探索**（下潜 / 新深度 / 新矿脉） | 进度与里程碑 |

**两者可以不同步，而且应该允许不同步**：

> 你可能**已经知道**有一条含氯的路线（B7 的残页到手了），
> 但**还没解锁**处理它的分离原语（B8 还没给）；
> 反过来，机制可以先给你，而**你还不知道拿它干什么**。

**⚠️ 若把两者合成一个**（例如"解锁残页就自动解锁机制"），
**"知道"就会自动等于"能用"** —— 而那会把 B8 的整个渐进设计抹掉，
也会让"读到一条路线但暂时做不到"这个**很真实的体验**消失。


### States and Transitions
**本系统有一条"解锁状态"**（但与 B8 的机制解锁不同 —— 见澄清 3）：

| 状态 | 含义 |
|------|------|
| **初始条目** | 开局就有 —— **刚好够跑通第一条线**（水电解 → H₂ + O₂，⑥） |
| **残页未得** | 那条知识**存在，但你还没到过那里** |
| **已获得** | 你已经走到那里（或实验发现了这条事实 —— 见澄清 2） |

**⚠️ 与 B8 的接缝（必须划清）**：
**B7 管"你知道吗"，B8 管"你能用吗"。** 两者**可以不同步**，而且**应该允许不同步**。

## Formulas
**本节明确写：B7 没有自己的公式。**

它的每一个数值都必须**追溯到一个上游**：

| 百科里显示的 | 来自 |
|--------------|------|
| 一条路线在什么条件下给出什么 | **A3**（求值）+ **A2**（化学） |
| 该路线的**代价**（能耗 / 纯度 / 耗时） | **A6**（代价面） |
| 某产物的**档位**与分离路线的对比 | **B3**（分级与分离） |

> **这正是三条上游契约（⑨）在数值上的形式**：
> **B7 是【读取与组织】，不是【计算】。**
> —— 若百科里出现一个"算出来的数"而它追溯不到上游，那就是一处越界。

## Edge Cases
| 边界 | 行为 | 依据 |
|------|------|------|
| **百科给的解在当前条件下不成立**（浓度不够 / 深压不够） | **允许** —— 百科给的是"路线"，**不是"保证"**；玩家会发现条件不够，**而那就是学习** | ① ② |
| **玩家照百科跑，却出了意外产物** | **这是设计要的，不是 bug** —— ② 明写"不给豁免" | ② |
| **同一产物有多个可行解时给哪一个** | 给**最简单的那个**（"起跑线"原则）—— **不是最优** | ① |
| **残页重复获得** | **幂等**（不重复计数） | ⑥ |
| **百科条目引用了尚未解锁的机制** | **允许** —— 澄清 3：**知道 ≠ 能用**；"知识先于能力"是正常情形 | 澄清 3 |
| **玩家实验发现的事实被记进百科** | 与残页获得**走同一套状态**（"已获得"） | ⑧ |
| **百科条目与玩家自己的工艺"冲突"** | **不冲突** —— 一个是**事实**（百科）、一个是**方案**（B9）；**玩家可以做得比百科更好**（那正是 P3 想要的） | ⑧ |

### 两条由定位推出的性质

1. **它是唯一一个【只读】的玩家系统。**
   它不产出任何东西 —— **它把上游的事实组织成人能读的东西。**
   → 所以它的错误形态很特殊：**它不会算错**（因为不算），
   **它只会"说错"** —— 而那是**误导**，比算错更难发现（与 A6 的 §Dependencies 同源）。
2. **它是"发现"这个循环的闭合点。**
   三条途径（实验 / 探索 / 观察）的产物最终都汇到这里（事实 → 百科）或 B9（工艺 → 作品集）。
   → **若 B7 缺席，"发现"就无处可存** —— 玩家搞明白的规律只能留在脑子里。

## Acceptance Criteria

**六条，第一条与第二条是一对。**

| # | 验收项 | 通过标准 |
|---|--------|----------|
| **1** | **非最优测试** | 百科**不得**给出最优参数 —— 它给的必须是"**一条**可行解" |
| **2** | **无豁免测试** | 照百科的条件跑，**条件不对必须照样出意外产物** —— 不得因为"是百科推荐的"而豁免 |
| **3** | **代价可见测试** | 每条可行解**必须带它的代价**（能耗 / 纯度 / 耗时） |
| **4** | **不完整测试** | 百科**不得**给出后续产物的**完整路线图** |
| **5** | **只读测试** | 百科里的**每一个数值都必须能追溯到上游系统** —— 出现"自己算出来的数"即为越界 |
| **6** | **起跑线测试** | **零化学基础的玩家能靠百科把第一条线跑起来** —— **这是它存在的全部理由** |

> **第 1 与第 2 条必须同时成立**，才构成"**入门坡道，不是答案本**"：
> 只满足第 1 条（不给最优）但它给了豁免 → 百科变成"抄了就不会错"的作弊本；
> 只满足第 2 条（不给豁免）但不给可行解 → 那它就什么都没给。
