## Player Fantasy
**方向：**「**这一局是我的海。**」

但它的幻想**不是"随机带来新鲜感"** —— 而是概念文档那四条约束给的：**公平、可通达、有预算**。
**随机性被用来制造【不同的开局】，而不是制造【不公平】。**

**反例**：开局随机到缺关键元素 → 那是"这局运气不好"，**而 P2 的整个立场是"不是运气"**。

**而澄清 3 给它加了一条更硬的边界**：
**可以改"东西在哪"，不可以改"东西是什么"** ——
所以玩家学到的化学**在每一局都成立**。**那才是"我的海"，而不是"另一款游戏"。**

### 澄清 1：**「布局」的翻译** —— 这是**第三次**同一类问题

| 哪一轮 | 机制语言里的空间词 | 真相 |
|--------|-------------------|------|
| **B5** | "**旁边**爆了" | **连锁只能沿图的边**（F-B5-1） |
| **C1** | "**越深**" | **深度是一条一维轴**（F-C1-1） |
| **C4** | "**随机化布局**" | ### **= 一条轴上的分布** |

> **"布局"在本作里 = 【矿脉在哪一段、丰度多少、各分段多长】。**
>
> **⚠️ 这不是措辞问题** —— 若不翻译，实现者会去找一个二维/三维世界模型
> （**前两次的教训已经证明这条路是死的**）。

### 澄清 2：为什么"**分层权重**"可以变、而"**深度结构**"不能变

两句话听起来会撞：

| 出处 | 说的是 |
|------|--------|
| **C1 的契约** | **不得假设可以自由生成深度结构** |
| **概念文档的四条约束** | **分层权重**（可以随机） |

**两句同时为真的方式**：

> ### **曲线的【形状】不变，而它在轴上的【分配】可变。**
> - **函数家族固定** —— 带宽随深度单调下降、耗氧单调上升…（**这些关系是 C1 定的**）；
> - **而分段的长短可变** —— S1 占多长、S4 占多长（**那就是"分层权重"**）。

### 澄清 3：为什么**元素集绝不能随机化**（这条要写下来）

用户选项里排除了"也随机化元素集" —— 而**理由值得单独写**，因为它护的是本作最核心的承诺：

| # | 理由 |
|---|------|
| **①** | **知识不可迁移** —— 玩家学到的化学（"氯会氧化"、"矿石要炼"）**在某局成立、在另一局不成立** → **那会把"学习真化学"变成"学习这一局的假化学"**，而 P2 的整个卖点就是**真化学** |
| **②** | **与 Risk #9 冲突** —— 那份"仅矿脉可得"的清单是**全局**的（判据不随局变） |
| **③** | **它会让 B7 的百科失效** —— 百科装的是**事实**，而**事实不该随局变** |

> **→ 所以 C4 的随机性有一个硬边界：它可以改【东西在哪】，不可以改【东西是什么】。**

### States and Transitions
**它没有运行时状态 —— 它在【开局生成一次】**（同 A2/A6/C1 的"不适用"，但要说明它留下什么）。

| 它留下 | 说明 |
|--------|------|
| **种子** | 世界的身份证 |
| **生成算法的版本** | 否则老存档重放不出原世界（与 A4 的 schema 版本化同一类问题） |

**⚠️ 一条重要的推论**：**"种子 + 生成算法 = 世界"** —— 所以它**不必存整个世界**。
**而这也意味着：生成算法一变，老存档就回不到原来的世界。**
→ **这与 A1 的"元素表 schema 必须版本化"、A4 的"schema 内容指纹"是同一条纪律。**

## Formulas
### ① 元素预算的随机范围（**概念文档已给**）

```
元素预算 = 基准值 × (1 ± 30%)        ← 概念文档 line 409
```

### ② 可通达性判定（**四条约束里最关键的一条**）

```
开局可通达  <=>  存在一条从起步条件出发、只用开局可得元素就能跑通的起步链
```
> **它保证"公平开局"不是一句口号** —— 而它也是验收里的"公平测试"。

### ③ 种子 → 世界（**确定性**）

```
世界 = 生成算法(种子, 版本)          ← 同种子同世界（⑥）
```

### ④ 随机化的对象（**②③ 已定**）

```
可变：矿脉在轴上的位置 / 丰度 / 数量 ；各分层分段的长短（分层权重）
不可变：函数形状（C1）· 元素集（Risk #9 的全局清单）· 四条约束本身
```

## Edge Cases
| 边界 | 行为 | 依据 |
|------|------|------|
| **随机到缺关键元素** | **不允许** —— **可通达性判定必须拦住它**（否则那就是"运气不好"） | ② ⑤ |
| **老存档在新版本下重放不出原世界** | **已知后果** —— 所以**生成算法版本必须存**（同 A4 的 schema 版本化） | ⑦ |
| **玩家想重开一局** | `[待定]` —— 见 §Open Questions（同一存档 vs 新种子） | —— |
| **种子相同但版本不同** | **不是同一个世界** —— 版本是映射的一部分 | ③ |
| **随机化到"元素集"** | **禁止** —— 那是 C4 的硬边界（澄清 3） | ④ |
| **生成出不可达的起步条件** | **不允许** —— 生成失败必须重抽，不得交付一个不可玩的开局 | ⑤ |
| **分层权重随机到某段长度为 0** | `[待定]` —— 需确认"零长度段"是否合法（它会让某深度不可达） | §Open Questions |

| # | 验收项 | 通过标准 |
