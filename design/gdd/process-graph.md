## Summary

把玩家连出来的**节点 + 边**的工艺图，用 **A3 定义的求值语义**跑成**连续流** ——
决定谁先取料、产物往哪流、以及"接不住"时会发生什么。

## Overview

**它在"数据 → 世界"这条线上的位置**：
`A1 元素（数据）` · `A2 化合物与步骤（数据）` → `A3 求解语义` → **`A5 对图求值（连续流）`**。
**A3 说"一个步骤怎么算"，A5 说"整张图怎么同时流动"。**

### 🚨 三条承重约束（都不是本系统的自由，且第一条来自一条明确的警告）

**① 本体是【连续流】，不是批次结算。**

> 概念文档原文（Core Mechanics #4 下的一条警告）：
> **「T0 v1–v4 是"批次"模型……而本作本体是连续流。」**
> **「不要把"每批结算""清洗一次算一批"这类概念写进任何系统 GDD」**
> —— **结垢是连续累积速率，清洗是一段停机时间，不是回合制。**

**这条警告就是给 A5 的**（"连续流"住在这里）。**A5 的任何设计都必须是连续量 + 速率，
而不是"跑一批 → 出结果 → 再跑一批"。** 那条警告还说清了它为什么危险：
**这类"原型的方便"是很容易悄悄变成设计债的。**

**② 管网是【节点 + 边】的逻辑图，不是逐 tile 模拟。**
（同样来自 Core Mechanics #4。）→ 这直接决定了 A5 的性能形状与数据形状。

**③ 产物必须【立刻】被下游或储罐接住。**（Core Mechanics #4：「输入即刻变输出，产物必须立刻被下游或储罐接住。」）
→ **"接不住"时必须有一个明确的行为** —— 这是本系统最需要在 §Core Rules 里定死的一条。

### 边界（它不是什么）

- **不是数据** —— 元素属 A1、化合物与步骤属 A2、**求值语义属 A3**。
- **不是连线编辑** —— 玩家怎么连、四种连线决策属 **B1**（A5 提供"图上有什么"，B1 提供"怎么编辑"）。
- **不是热力图** —— 数据怎么画属 **B12**（A5 暴露状态，B12 负责呈现）。
- **不是性能预算本身** —— **B19 专管"管网 tick 的预算"**，且 **B19 只依赖 A5** → A5 是它的唯一上游。
- **不是深度/带宽** —— 深度分层与通量阶梯属 **C1**（T3）。

## Player Fantasy

`[待定 —— 方向：**"我连出来的东西会自己流动。"**
A5 是 P3「连出来的工艺属于玩家」在【动态】层面的兑现：
玩家不是在按一个"运行"按钮，而是在**看着自己搭的系统持续工作**。
连续流的核心手感是**"它一直在动"** —— 而批次模型会把它变成"我点一下、它算一下"。

反例（要警惕的）：玩家改了一根线，却看不到流动立刻变化 —— 那会让人怀疑"图"是不是真的接上了。
需确认：流动的**可见性**属 A5 还是 B12。]`

## Detailed Design

### Core Rules

`[待定 —— 草案，逐条待确认：]`

1. **图模型 = 节点 + 边**（逻辑图）。**不得引入逐 tile 或逐格的概念。**`[待确认]`
2. **求值语义来自 A3** —— A5 **只应用、不重定义**（不得自己定义求值顺序）。`[待确认]`
3. **活跃集**：**A5 决定本 tick 哪些机器参与求解**（A3 只求解该集合）。`[待确认]`
4. **连续流**：所有量都是**连续速率**，不是"每批结算"。结垢等累积量是**速率积分**，
   清洗是**一段停机时间**（不是"算作一批"）。`[待确认]`
5. **"接不住"的行为**：产物必须立刻被下游或储罐接住 —— **接不住时怎么办必须定死**
   （阻塞上游？溢出？还是丢弃？**丢弃 = 物质凭空消失，违反 P2**）。`[待确认]`
6. **环路**：玩家可以连出循环工艺（这是玩法）—— **A5 必须处理环上的求值**（不能死循环）。`[待确认]`
7. **性能形状**：规模随**管段数**增长（不是随原子数）→ 与 A1（原子数）、A3（机器数）**三者是不同维度**。`[待确认]`
8. **tick 与 B19 的接缝**：A5 定义"一次求值要做什么"，**B19 决定"一个 tick 里装得下多少"**。`[待确认]`

| **B9** 工艺命名与工艺卡 | 一张图 = 一个可辨识、可命名、可存取的实体 | 不得假设**工艺可以脱离图单独存在** |
| **B12** 热力图主图层 | 每个节点的**当前读数**（状态/速率） | 不得假设**读数可以事后重建**（必须实时暴露） |
| **B16** 存档 / 读档 | 图的结构与运行状态可序列化 | 不得假设**图是纯拓扑**（运行状态也在里面） |
| **B17** 新手引导 / 教程 | "一条完整的线"是什么样子（可被引导的单元） | 不得假设**教程可以自己造一张图** |
| **B19** 性能预算与管网 tick | **一次求值要做什么**（工作量形状） | 不得假设**求值成本与管段数无关**；不得假设**可以按原子数估算管网开销** |
| **C1** 深度分层与通量阶梯 | 通量随深度的变化如何影响流动 | 不得假设**深度只影响物流速度**（也影响可达性与布局） |
| **C3** 飞船与零件 | 一张可求解的制造图 | 不得假设**飞船可以绕过工艺图** |

## Formulas

`[待定 —— 方向：]`
1. **图求值顺序**：**由 A3 的语义决定**（层间抢料 + 层内联立）—— 本处不重定义。
2. **连续流速率的积分**：结垢等累积量 = 速率对时间的积分（**不是按批累加**）。
3. **"接不住"的判定式**：`下游容量 + 储罐余量 < 本 tick 产出量` → 触发规则 ⑤ 定的行为。
4. **环路的收敛**：`[待定]`

## Acceptance Criteria

`[待定 —— 方向：]`
- **连续流测试**：同一张图在连续时间上运行，结果必须**随速率连续变化**，
  **不得出现"按批跳跃"**（这是承重约束 ① 的可测形式）
- **接不住测试**：构造"产出超过下游+储罐容量" → 必须走规则 ⑤ 定的行为，**绝不丢弃物质**
- **环路测试**：含环的图必须能求解且**不死循环**
- **语义一致性测试**：同一张图在 A5 上的结果，必须与 A3 单独求值的语义**一致**
- **规模测试**：数百管段的图在单 tick 内可解（与 B19 联测）
